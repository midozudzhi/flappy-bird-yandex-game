# 🐦 Flappy Bird - Браузерная игра для Яндекс Игр

Простая и увлекательная браузерная игра в стиле Flappy Bird, полностью написанная на HTML, CSS и JavaScript. Готова к публикации в Яндекс Играх!

## 🎮 Особенности

✨ **Полностью браузерная** — без серверной части  
🎯 **Простая механика** — кликните для полета, избегайте препятствий  
📱 **Адаптивная** — работает на ПК и мобильных устройствах  
🖱️ **Мультиуправление** — мышь и сенсорный экран  
🎨 **Минималистичный дизайн** — голубое небо, зеленая трава, яркая птичка  
⚡ **60 FPS** — плавная анимация  
🔌 **Готова к интеграции** — заглушки для SDK Яндекс Игр  

## 🚀 Как начать

### Вариант 1: Локально

1. Клонируйте репозиторий:
```bash
git clone https://github.com/midozudzhi/flappy-bird-yandex-game.git
cd flappy-bird-yandex-game
```

2. Откройте `index.html` в браузере (двойной клик или перетащите в браузер)

### Вариант 2: На сервере

Просто скопируйте все три файла (`index.html`, `style.css`, `script.js`) на свой веб-сервер и откройте в браузере.

### Вариант 3: GitHub Pages

1. Включите GitHub Pages в настройках репозитория
2. Укажите ветку `main` как источник
3. Ваша игра будет доступна по адресу: `https://midozudzhi.github.io/flappy-bird-yandex-game/`

## 📋 Требования

- Современный браузер с поддержкой Canvas API
- JavaScript включен
- Ширина экрана минимум 320px (для мобильных)

## 🎮 Как играть

1. **Запустите игру** — откройте `index.html` в браузере
2. **Управление** — кликните мышью или нажмите на экран для полета птицы
3. **Цель** — пролетите как можно дальше, избегая зеленых труб и земли
4. **Счет** — за каждое успешно пройденное препятствие вы получаете 1 очко
5. **Game Over** — при столкновении с трубой или землей игра заканчивается
6. **Переиграть** — нажмите кнопку "Играть снова"

## ⚙️ Конфигурация

Вы можете легко настроить игру, изменив параметры в объекте `CONFIG` в `script.js`:

```javascript
const CONFIG = {
    canvasWidth: 400,           // Ширина игровой области
    canvasHeight: 600,          // Высота игровой области
    
    bird: {
        x: 60,                  // Начальная X позиция птицы
        y: 150,                 // Начальная Y позиция птицы
        width: 30,              // Ширина птицы
        height: 24,             // Высота птицы
        gravity: 0.6,           // Сила гравитации
        jumpPower: -12,         // Сила прыжка (отрицательное = вверх)
        maxFallSpeed: 12        // Максимальная скорость падения
    },
    
    pipes: {
        width: 50,              // Ширина трубы
        gap: 120,               // Промежуток между верхней и нижней трубой
        distance: 200,          // Расстояние между парами труб
        speed: 5,               // Скорость движения труб
        minHeight: 50,          // Минимальная высота верхней трубы
        maxHeight: 300          // Максимальная высота верхней трубы
    },
    
    groundHeight: 60,           // Высота полосы земли
    fps: 60                     // Целевые FPS
};
```

## 🔌 Интеграция с Яндекс Играми

В `index.html` уже подготовлены заглушки для SDK Яндекс Игр:

```javascript
window.YaGame = {
    save(data) { /* сохранение данных */ },
    load() { /* загрузка данных */ },
    showAd(callback) { /* показ рекламы */ },
    submitScore(score) { /* отправка результата */ }
};
```

При публикации в Яндекс Играх раскомментируйте соответствующие строки в `script.js`:

1. **Сохранение результатов**: строка ~374
2. **Показ рекламы**: строка ~375
3. **Отправка результатов на лидерборд**: строка ~149

Подробнее в [документации Яндекс Игр](https://yandex.ru/dev/games/).

## 🎨 Кастомизация

### Изменение цветов

Отредактируйте значения в `style.css` и `script.js`:

- **Небо**: `#87CEEB`, `#E0F6FF`
- **Трава**: `#2d8659`, `#1a5033`
- **Птица**: `#FFD700`, `#FFA500`, `#FF6B6B`

### Изменение сложности

Отредактируйте параметры в `CONFIG`:

- **Легче**: увеличьте `pipes.gap`, уменьшите `bird.gravity`
- **Сложнее**: уменьшите `pipes.gap`, увеличьте `pipes.speed`

### Добавление звука

Добавьте элементы `<audio>` в `index.html` и воспроизводите их в `script.js`:

```javascript
const flapSound = new Audio('flap.mp3');
flapSound.play();
```

## 👨‍💻 Разработка

### Изменение структуры игры

1. **Добавить новый тип препятствия**: добавьте тип в `createPipe()` и `drawPipes()`
2. **Добавить power-ups**: создайте новый массив в `gameState` и обновите логику коллизий
3. **Добавить уровни**: добавьте функцию `selectLevel()` и измените `CONFIG` динамически

### Отладка

Откройте консоль браузера (F12) для просмотра логов:
- `Flappy Bird Game Initialized` — игра запустилась
- `YaGame.*` — вызовы функций интеграции
